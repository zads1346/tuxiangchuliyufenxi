# 训练／验证集与测试集近重复审计

本审计只使用图像本身，不查看模型输出或表现，也不修改正式划分。对 `splits_valid.json` 中训练和验证图像合计 3,673 张，与官方测试有效子集 3,662 张作跨集合比较。

每张图转灰度、用 Lanczos 缩放到 9×8，比较每行相邻像素是否满足右侧大于左侧，得到 64 位差值哈希（dHash）。使用汉明距离不超过 5 筛选候选，并逐对目视审查候选图像。共 24 对候选：23 对照片几乎相同（距离为 0 或 1），1 对是不同照片（距离为 5）。其中 22 对跨训练与测试，1 对跨验证与测试；23 张不同测试图片的 ID 保存在 `duplicate_test_ids.json`。完整配对及人工判定见 `cross_split_dhash_review.json`。为避免再分发原始照片，仓库不包含审阅联系表。

运行 `python data/audit_cross_split_duplicates.py` 可重算候选并检查其与保存的目视记录一致，脚本不会改写数据或划分。由于不同库版本可能影响图像解码或缩放，重算不一致时应检查环境和候选，而不是覆盖目视结论。

阈值和 dHash 并不保证找出所有近重复：裁剪、镜像、色调变化、不同姿势或同一动物的其他照片可能漏检，其他相似画面也可能误报。目视判断仅针对照片是否接近，不确认动物身份；不能据此认定集合已达到动物级独立。23 张列表可用于附加敏感性分析，但该分析与官方完整测试集合结果应分别标识。
